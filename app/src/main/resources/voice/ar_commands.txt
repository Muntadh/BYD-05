# BYDMate built-in voice commands, Arabic (قاموس الاوامر الصوتيه العربي).
#
# This file mirrors ru_commands.txt for Arabic: the same commands on the right of "=>", copied
# from the Russian file, with Arabic phrases (Modern Standard Arabic plus common Iraqi and Gulf
# forms) on the left. Keep the two in step: a command added there gets its phrases here.
#
# A phrase runs offline only when it equals one phrase of this file, word for word. Anything
# else goes to the cloud agent (or gets "not understood" without it). "A و B" and "A ثم B" run
# when every part is a command of this file on its own, so a template never holds a standalone
# "و" or "ثم" (an attached "والسقف" is one word and is fine).
#
# Both the phrase and the template words are normalized the same way, and templates are written
# already normalized: no tashkeel or tatweel; أ إ آ ٱ -> ا, ة -> ه, ى -> ي, ؤ -> و, ئ -> ي;
# punctuation out; "%" -> "بالمئه"; number words -> digits ("خمسه وعشرين" -> 25), so number
# places are written as digits, slots or ranges. Filler words (رجاء رجاءا ممكن بليز شكرا حبيبي
# اريد اريدك ابي ابغى يا عيني, and "من فضلك", "لو سمحت", "لو تسمح") are dropped from the phrase
# and may not appear here.
#
# Lines ("#" starts a comment; a line starting with a space continues the previous one):
#   rule NAME: a|b|...                       alternatives, used as <NAME>
#   list NAME: forms => VALUE ; forms => VALUE
#                                            slot used as {NAME}; forms are |-separated phrases in
#                                            template syntax or number ranges like 10..49
#   range NAME: 16..30                       slot whose value is the number said
#   TEMPLATE => COMMAND                      a phrase and what it runs
#   solo TEMPLATE => COMMAND                 the same, but only as the whole phrase, never as one
#                                            part of "A و B" (a phrase without its own verb would
#                                            take the other part's verb there)
# Template syntax: words, <rule>, {slot}, [optional part], (a|b) choice, a|b at the top level.
# COMMAND: dispatch strings joined by " + ", each {slot} replaced by its value; a value of several
# symbols "a,b" repeats the command once per symbol, in that order. Built-ins:
#   TEMP +1, TEMP -1    cabin temperature one step up or down
#   VOL PAYLOAD         media volume: +1, -1, mute, unmute or a level
#   ASK QUESTION        a question answered from the car's readings, nothing runs: outside_temp,
#                       cabin_temp, soc, range, ac_temp; a value the car does not report sends
#                       the phrase to the agent
#   MUSIC               Yandex Music's personal mix, as the agent's play_music starts it with no
#                       query
#   NAVIGATE SHORTCUT   a route to Home or Work (home, work), as the agent routes "home", started
#   ROUTE SHORTCUT      the same route, only built: the driver starts it
#   OPEN_NAVIGATOR      the navigator chosen for routes, launched as the agent's launch_app does

# ---- Spoiler -------------------------------------------------------------------------------
# "ارفع" and "نزل" are the spoiler's own up and down here, the opposite of what they mean for a
# window, so the window verb rules are not used. A car without a powered spoiler answers that it
# has none; a standing car with the spoiler up refuses down and auto. There is no "auto off":
# that phrase goes to the agent, which explains that up or down switches to manual.

rule spoiler: الجناح|الجناح الخلفي|السبويلر|الاسبويلر
rule spoiler_up: ارفع|ارفعي|طلع|صعد|افتح|فتح
rule spoiler_down: نزل|نزلي|اخفض|دخل|رجع|سكر|اغلق
<spoiler_up> <spoiler> => 打开尾翼
<spoiler_down> <spoiler> => 关闭尾翼
<on> <mode> <auto> (للجناح|مال الجناح|للسبويلر) => 尾翼自动模式
(<set>|حول) <spoiler> (علي|الي) [الوضع] <auto> => 尾翼自动模式
solo <spoiler> (علي|الي) [الوضع] <auto> => 尾翼自动模式

# ---- Drive mode ----------------------------------------------------------------------------

# switch sport on.

    <mode> (العادي|عادي|الطبيعي|النورمال|نورمال)|نورمال مود => 普通模式 ;
    <mode> (الرياضي|رياضي|السبورت|سبورت)|سبورت مود => 运动模式 ;

    <mode> (الرمل|الرملي|الرمال) => 沙地模式 ;
    <mode> (الطين|الطيني|الوحل) => 泥地模式 ;
    <mode> (الجبل|الجبلي|الجبال) => 山地模式 ;
    <mode> (الذكي|ذكي|السمارت) => 智能模式
(<on>|<set>) {drive} => {drive}
(حول|غير|بدل) (الي|علي) {drive} => {drive}
solo {drive} => {drive}

# ---- Questions -----------------------------------------------------------------------------
# Answered from the car's own readings. Weather, charging stations and anything longer stay
# with the agent; a question never takes part in "A و B". "كم باقي كيلو" stays with the agent
# too: on a route it asks for the distance left, not for the range.

rule ask_how: كم|شكد|شقد|شنو|ماهي|ما هي
rule temp_n: الحراره|درجه الحراره
rule outside: برا|بره|خارج السياره|بالخارج|في الخارج
rule cabin: داخل السياره|بالسياره|في السياره|جوه|بالداخل
solo [<ask_how>] <temp_n> <outside> => ASK outside_temp
solo [<ask_how>] درجه الحراره الخارجيه => ASK outside_temp
solo [<ask_how>] <temp_n> <cabin> => ASK cabin_temp
solo [<ask_how>] درجه الحراره الداخليه => ASK cabin_temp
solo [<ask_how>] (نسبه الشحن|الشحن|نسبه البطاريه|شحن البطاريه) => ASK soc
solo (كم|شكد) (باقي|بقي) (شحن|من الشحن|بالبطاريه) => ASK soc
solo [<ask_how>] (المدي|المدي المتبقي|مدي القياده|مدي البطاريه|الرينج) => ASK range
solo (علي كم|علي شكد|شكد|كم) [حاط|مضبوط] <ac> => ASK ac_temp
solo [<ask_how>] (حراره|درجه حراره) (المكيف|التكييف) => ASK ac_temp
